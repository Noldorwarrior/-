# ЦПИКП — Центр привлечения инвестиций и корпоративного партнёрства НИЯУ МИФИ

Полный пакет документов для создания ООО «ЦПИКП» при НИЯУ МИФИ — единой точки входа для бизнеса с прямым подчинением ректору.

## Ключевые метрики (Set B, базовый сценарий)

| Параметр | Значение |
|:---------|:---------|
| TCV 10 лет | ~38,4 млрд руб. |
| Cash-in 10 лет | ~20,6 млрд руб. |
| NPV (r=12%) | 7,66 млрд руб. |
| ROI кумулятивный (TCV / CI) | 626% / 289% |
| Мультипликатор (TCV / CI) | 7,3x / 3,9x |
| Break-even | 15–20 мес. |
| Бюджет Год 1 (100% KPI) | ~168 млн руб. |
| Хедж Год 1 (0% KPI) | ~140 млн руб. |
